System Proposal · Desktop App

E-Sumbong: Local Governance and Community Issue Resolution System

October 14 – December 1, 2025 · STI College Legazpi · Advanced Database Systems, Event-Driven Programming and Enterprise Architecture

Description

A desktop application that gives barangay residents and the Local Government Unit (LGU) one structured channel for community concerns. Residents log in to file reports, track their status and read official announcements, while barangay officials manage reports, update their status and post announcements. The project was developed as a desktop application using C# and Windows Forms, with MongoDB for data storage.
