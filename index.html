E-Sumbong: Local Governance and Community Issue Resolution System

October 14 – December 1, 2025 · STI College Legazpi · Advanced Database Systems, Event-Driven Programming and Enterprise Architecture

Level 0 DFD: Context diagramFull size ↗

Description

A desktop application that gives barangay residents and the Local Government Unit (LGU) one structured channel for community concerns. Residents log in to file reports, track their status and read official announcements, while barangay officials manage reports, update their status and post announcements. Because it runs as a stand-alone desktop app instead of a website, it stays usable in areas with limited or unstable internet.
